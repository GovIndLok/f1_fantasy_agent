# F1 Fantasy Agent Glossary

## Roles

* **Player**: The end-user of the system (casual or competitive F1 Fantasy player).

## Core Concepts

* **Budget**: The in-game currency constraint for a player, strictly capped (e.g., $100M).
* **Transfer**: The action of swapping one driver or constructor for another in a roster between race weeks.
* **Point Penalty**: A negative point deduction (e.g., -4 points) applied when a player exceeds their allotted free transfers.
* **Driver Price**: The current cost of a driver in the game, which fluctuates over multiple weeks.
