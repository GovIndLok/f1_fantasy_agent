# Data Schemas Documentation

This document outlines the Pydantic schemas used across the F1 Fantasy Agent project. By isolating schemas into their respective component folders, we maintain a modular architecture where data structures can evolve independently of the business logic.

---

## 1. Authentication Schemas
**Location:** [`app/auth/schema.py`](file:///home/gov03/project/f1_fantasy_agent/app/auth/schema.py)

### `UserCredentials`
Used to validate the JSON body for user registration and login.

* **Fields:**
  * `email` (str): The user's email address.
  * `password` (str): The user's plaintext password.
* **Where it is used:**
  * `POST /auth/register` (in [`app/auth/router.py`](file:///home/gov03/project/f1_fantasy_agent/app/auth/router.py))
  * `POST /auth/login` (in [`app/auth/router.py`](file:///home/gov03/project/f1_fantasy_agent/app/auth/router.py))

## 2. Roster Schemas
**Location:** [`app/rosters/schema.py`](file:///home/gov03/project/f1_fantasy_agent/app/rosters/schema.py)

### `RosterEntity`
Represents a single entity (Driver or Constructor) inside a user's roster.

* **Fields:**
  * `entity_id` (str): The unique ID of the driver or constructor (e.g., `max_verstappen`).
  * `name` (str): The display name.
  * `entity_type` (str): Either `'driver'` or `'constructor'`.
* **Where it is used:** 
  * Nested inside the `RosterResponse` schema.

### `RosterResponse`
Used to format the API response when a user requests their current team.

* **Fields:**
  * `player_id` (str): The UUID of the authenticated user.
  * `roster` (list[RosterEntity]): A list of the drivers and constructors currently owned by the user.
* **Where it is used:**
  * `GET /roster/me` (in [`app/rosters/router.py`](file:///home/gov03/project/f1_fantasy_agent/app/rosters/router.py))

## 3. F1 Analyst Agent Schemas
**Location:** [`agents/f1_analyst/schema.py`](file:///home/gov03/project/f1_fantasy_agent/agents/f1_analyst/schema.py)

### `ChatRequest`
Used to validate the incoming message from the user intended for the LLM agent.

* **Fields:**
  * `prompt` (str): The user's question or command.
* **Where it is used:**
  * `POST /chat` (in [`app/main.py`](file:///home/gov03/project/f1_fantasy_agent/app/main.py))

### `ChatResponse`
Used to format the final response returned by the LangChain agent, including the AI's text and the associated token cost.

* **Fields:**
  * `answer` (str): The final text response generated by the AI.
  * `cost_log` (dict): A dictionary containing token usage metadata (e.g., `{"total_tokens": 123}`).
* **Where it is used:**
  * `POST /chat` (in [`app/main.py`](file:///home/gov03/project/f1_fantasy_agent/app/main.py))
